### Gym Website Starter Template

## Tech Stack

* **Next.js 16**
* **React**
* **JavaScript (ES6+)**
* **Tailwind CSS**
* **Intersection Observer API**
* **Git & GitHub**

---

## Getting Started

### Installing dependencies

```bash
cd frontend
npm install
```

### Run development server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

---

## Build for Production

```bash
npm run build
npm start
```
